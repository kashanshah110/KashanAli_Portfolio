# Kashan Ali Portfolio (React + Vite + Three.js)

```bash
npm install
npm run dev      # local dev
npm run build    # production build -> dist/
```

## CV download
Put your real CV at `public/Kashan_Ali_CV.pdf` (keep the exact filename, or change `CV_URL` in `src/data.js`).
The bundled file is only a placeholder generated from your portfolio text.
